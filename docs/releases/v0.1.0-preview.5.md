# v0.1.0-preview.5

Test prerelease for Apple Silicon on macOS 14 or later. App version 0.1.0, build 5.

- The bundled LiteLLM gateway receives the Codex `session-id` as `x-litellm-session-id`. An explicit `x-litellm-session-id` takes priority.
- Desktop enables forwarding for the managed gateway when the server accepts the option. Managed LiteLLM continues to use its own credentials.

The local verification passed 356 Rust and 474 Swift tests. In the offline Codex → Switchyard → LiteLLM check, the session ID stayed stable across two turns in one conversation and differed in a new conversation. A live check of the installed local build matched both observed Codex IDs to the headers received by LiteLLM.

This Apple Silicon preview uses ad-hoc signing and has no Apple notarization. The bundled core snapshot includes uncommitted changes on top of `d9b1f692471e924549cde7a98d2ec56a8b482ad5` and integrates NVIDIA upstream `c365efe832822541024704aadf6a0d5c81cc0528`. The complete imported sources and their manifest are available at the [desktop tag](https://github.com/eugenn/switchyard-desktop/tree/v0.1.0-preview.5).
