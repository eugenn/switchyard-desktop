# v0.1.0-preview.4

Apple Silicon (arm64) test prerelease for macOS 14 or later. App version 0.1.0, build 4.

### Changes
- Forward caller-provided `x-litellm-session-id` to the upstream by default (NVIDIA-NeMo/Switchyard PR #1001). Switchyard does not generate this header.
- Include the current desktop Jev classifier settings and direct classifier role descriptions.
- Redact configured secrets from child-process diagnostics.
- Preserve the current server routing changes and bundled Python, LiteLLM 1.97.0 and FastAPI 0.136.3.

### Validation
- 473 Swift tests passed, including user-data isolation checks.
- 124 switchyard-llm-client tests passed, including the session-header forwarding test.
- Rust formatting check passed.
- Imported snapshot matches the core working tree (821 files).
- Packaged app passed signature, macOS deployment target, pinned runtime and offline request smoke checks.
- DMG integrity and SHA-256 checksum verified.
- Gitleaks scanned the staged source tree, mounted DMG application and executable strings. No real API keys were identified; matches were file hashes and an existing diagnostic-redaction test fixture. No user authentication files were found in the app.
- Build 4 was installed in `/Applications` and launched; its server manifest matches the source snapshot.

### Preview limitations
- Ad-hoc signed; no Apple Developer ID signature or Apple notarization.
- Apple Silicon only.
- Core base: `d9b1f692471e924549cde7a98d2ec56a8b482ad5`; integrated NVIDIA upstream: `c365efe832822541024704aadf6a0d5c81cc0528`.
- PR commit `5438bd3d2eae5269e3736c622494da00975a99ab` was applied without creating a core commit. The snapshot is marked as containing tracked working-tree changes and does not pass the public release gate.
- Authenticated provider requests were not exercised for this build.

This test prerelease uses an explicitly approved exception to the clean/published-core and Developer ID/notarization release gates. The standard public release requirements remain unchanged. Core changes were not committed or pushed for this release.
