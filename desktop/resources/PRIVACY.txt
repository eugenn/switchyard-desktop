SWITCHYARD DESKTOP PRIVACY AND DATA FLOW

Codex routing: Codex sends prompts, code and tool results to Switchyard on
127.0.0.1:4100. Switchyard selects a model and sends the request to bundled
LiteLLM on 127.0.0.1:4101, which uses its separate ChatGPT sign-in.
Optional Jev routing sends classification context to TypeSafe and needs an API key.
Providers process data under their own terms.

Claude Code routing: Claude Code sends prompts, code and tool results to Switchyard
on 127.0.0.1:4100. Switchyard selects a Claude model and sends the request, and its
classifier calls, to api.anthropic.com using your Anthropic API key. The key is
stored in the system key vault and given only to the managed server; Claude Code
receives a placeholder. The app does not read or use Claude subscription sign-in
tokens. Anthropic processes data under its own terms and bills your API account.

The app stores settings, generated configurations and routing records under
switchyard-desktop/cross-platform in the platform application-data directory.
LiteLLM tokens are app-private files there, not OS-vault entries; stronger token
protection remains a release blocker. TypeSafe and Anthropic keys use the system
key vault. Codex retains its own account directory. The app temporarily
creates CODEX_HOME/switch.config.toml for routing, not the user's config.toml.
Setup imports are explicit drafts and do not transfer credentials or history.

Do not publish credentials, custom prompts, request logs or personal paths.
Automated tests use injected temporary paths and mock providers, never accounts.
Removing source code does not remove user data, account sessions or installed apps.
